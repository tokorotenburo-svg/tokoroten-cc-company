## デザイン方針（確定）

**コンセプト：カッコつける、でも抜け感は死守**

| 軸 | 内容 |
|----|------|
| ベース | ダーク（黒ベース） |
| 抜け感 | コピー・イラスト・ユーモアセクション・意外な動き |
| 技術力 | ローディングアニメーション（ロゴ押し出し）・GSAP演出 |
| 演出 | 一部ページで背景色反転 |
| FV | 画面固定 → 切り替えトランジション（縦スクロールなし） |

### ローディング演出（必須）
- Three.jsまたはGSAPでロゴ（「と」）を3D押し出しアニメーション
- ところてんが型から押し出されるイメージ
- サイト名の由来とデザインが直結する

### 抜け感チェックリスト（デザイン中に確認）
- [ ] 「初めまして。楽しいこととプリンが好きです。」が生きているか
- [ ] 遊び心セクションがカッコよさと浮いていないか
- [ ] イラストが整いすぎていないか
- [ ] どこかに予想外の動きがあるか
