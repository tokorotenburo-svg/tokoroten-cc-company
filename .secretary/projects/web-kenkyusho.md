# プロジェクト: Web研究所

## 一言で言うと
「Webを使って、体験の価値を研究・実験・発信していく自主プロジェクト」

企画 × デザイン × Web実装で、Webならではの希少性や特別な体験を作るための研究。

## 発端・背景
- 尊敬する同期（既卒・5歳上）のZINE制作・アーティストマネジメント活動に影響を受ける
- ZINEへの憧れ → 「でも自分の強みはWebだ」という気づき
- ZINEの価値は「紙媒体」ではなく「体験設計」にあると気づく
- → WebでもZINE的な特別感・希少性を作れるという確信へ

## コアコンセプト
> ZINEをWebで再現するのではなく、ZINEに感じた価値を、体験設計としてWeb上で再構成する

## ところてんのポジション
- アーティストではなく「価値を発見・言語化・編集・設計する人」
- 水のように器に合わせて形を変えながら価値を最大化する
- 企画屋・ディレクター・プロデューサー気質

## 実験アイデア（例）
- 1回しか見られないページ
- 時間帯によってしか開かないページ
- 期限が来ると消えるサイト
- 見る人ごとに内容が変わるページ
- 入力しないと開けないページ
- 誰かからURLを渡されないと気づけないページ
- アクセスするたびに変化するページ
- 人数制限のあるページ
- リアルの場でもらったQRからしか入れないページ
- 複数人が関わらないと成立しないページ

## SNS発信の型（案）
```
Web体験実験 #XX
- どんな制限 / ルールを入れたか
- どういう体験を狙ったか
- 実装URL
- 次は何を試したいか
```

## 大事にしたい価値観
1. 自分の強み（Web実装）を殺さない
2. いきなり完成作を狙わない。量・実験・検証を優先
3. 内容より構造を研究する
4. 企画屋・ディレクター的な視点を育てる
5. 将来のブランディング・独立・共同企画につなげる

## 将来的な接続先
- アーティスト・ブランドとの共同企画
- Webを使ったブランディング
- 体験設計を軸にした仕事
- 自身の独立・企画活動

## 課題・懸念点
- 「一回しか見られないページ」系はすでに先例多数 → 差別化は**実験の解剖・言語化**にある
- SNS継続が最難関 → 最初から仕組みを設計すること
- ポートフォリオ（tokoroten.com）との位置づけを明確にする必要あり
